# Мой сайт

Личный сайт «для всего»: скачать видео, футбол, заметки, пароли и ссылки — в одном месте.
Работает на GitHub Pages, без сервера и без регистрации на чужих сервисах.

## Что умеет

| Раздел | Что внутри |
|---|---|
| 🔐 **Вход** | Логин и пароль без почты и телефона. Если забыли — 3 способа войти (см. ниже). |
| 🎬 **Видео** | Вставьте ссылку с YouTube, Instagram, TikTok, VK, Facebook, X и др. — видео скачивается **прямо с сайта** через ваш сервер (выбор качества, MP3, просмотр перед сохранением). Запасные способы: онлайн-сервисы и команда `yt-dlp`. |
| ⚽ **Футбол** | **Телеканалы в прямом эфире** прямо на сайте, плеер для YouTube/Rutube, поиск обзоров матчей, ссылки «где смотреть» и «счёт и новости», избранные видео. |
| 📝 **Заметки** | Заметки, планы, идеи и задачи. Строки вида `[ ] купить хлеб` становятся галочками. Закрепление, поиск, фильтры. |
| 🔑 **Пароли** | Хранилище паролей с генератором, копированием в один клик и поиском. |
| 🔗 **Ссылки** | Закладки по категориям, избранные показываются на главной. |
| ⚙️ **Настройки** | Смена логина/пароля, вопросов, кода восстановления, автоблокировка, тема, резервная копия. |

## Если забыли логин или пароль

На экране входа нажмите **«Забыли логин или пароль?»**. Есть три способа:

1. **Подсказки** — показывается начало и конец логина (`a••b`) и ваша подсказка к паролю.
2. **Секретные вопросы** — правильно ответьте на **любые 2 из 3**. Регистр букв, «ё/е» и лишние пробелы не важны.
3. **Код восстановления** — 16 символов, который сайт показал при регистрации. Работает, даже если забыли всё.

После восстановления сайт покажет ваш логин и предложит задать новый пароль.

## Как включить сайт на GitHub

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите ветку с этим кодом и папку **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу:
   `https://zudzudabuayub.github.io/no-name/`

> Для приватного репозитория GitHub Pages доступен только на платном тарифе.
> В коде нет ваших данных и паролей — они хранятся только в браузере, поэтому публичный репозиторий безопасен.

### На телефоне как приложение

Откройте сайт в браузере → меню → **«Добавить на главный экран»** (Android/Chrome) или
**«Поделиться» → «На экран „Домой“»** (iPhone/Safari).

## Где хранятся данные и насколько это безопасно

- Все данные лежат **только в вашем браузере** (localStorage) и **зашифрованы** AES-256-GCM.
  Ключ получается из логина и пароля (PBKDF2-SHA256, 250 000 повторов). Пароль нигде не сохраняется.
- Ничего не отправляется на сервер. Даже GitHub не видит ваши заметки и пароли.
- Ответы на секретные вопросы и код восстановления — запасные ключи к тем же данным.
  Выбирайте ответы, которые не знают посторонние, а код храните отдельно (на бумаге).
- Подсказку к паролю видит любой, кто откроет сайт на вашем устройстве, — не пишите в ней пароль.
- Сайт сам блокируется после бездействия (по умолчанию 15 минут) и при закрытии вкладки.

### Перенос на другое устройство и защита от потери

Данные живут в одном браузере. Если очистить данные браузера — они пропадут.
Поэтому время от времени делайте **Настройки → Резервная копия → Скачать копию**.
На новом устройстве откройте сайт и нажмите **«Загрузить резервную копию»** — затем войдите своим логином и паролем.
Копия тоже зашифрована.

## Скачивание видео прямо с сайта (свой сервер)

Страница на GitHub Pages не умеет запускать программы, поэтому скачивание делает маленький сервер
из папки [`server/`](server/) — как в проекте nova-downloader: он запускает
[yt-dlp](https://github.com/yt-dlp/yt-dlp), скачивает видео и отдаёт готовый файл вашему сайту.
Сервер ваш личный, защищён ключом `ACCESS_KEY`.

### Вариант 1. Бесплатно на Render (рекомендую)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/zudzudabuayub/no-name)

1. Зарегистрируйтесь на [render.com](https://render.com) через GitHub.
2. Нажмите кнопку выше → **Deploy**. Render соберёт сервер по файлу `render.yaml` (5–10 минут).
3. Когда появится зелёное **Live**, скопируйте адрес вида `https://moi-sait-downloader.onrender.com`.
4. В сервисе откройте **Environment** и скопируйте значение `ACCESS_KEY`.
5. На сайте: **Настройки → Сервер для скачивания** → вставьте адрес и ключ → **Проверить и сохранить**.

Если кнопка не сработала — вручную: **New → Web Service** → выберите репозиторий → **Language: Docker** →
**Root Directory:** `server` → **Instance Type: Free** → в **Environment Variables** добавьте
`ACCESS_KEY` (любой длинный пароль) и `ALLOWED_ORIGINS` = `https://zudzudabuayub.github.io` → **Create Web Service**.

> Бесплатный сервер Render засыпает через 15 минут без дела. Первое скачивание после паузы
> ждёт до минуты, пока он проснётся, — сайт это показывает.

### Вариант 2. На своём компьютере

Нужны Python 3.10+ и [ffmpeg](https://ffmpeg.org/). В папке `server`:

```bash
pip install -r requirements.txt
```

```bash
ACCESS_KEY=мой-секретный-ключ python app.py
```

(В Windows: `set ACCESS_KEY=мой-секретный-ключ` и затем `python app.py`.) Или через Docker:

```bash
docker build -t moi-sait-server server && docker run -p 8000:8000 -e ACCESS_KEY=мой-секретный-ключ moi-sait-server
```

В настройках сайта укажите `http://localhost:8000` — так скачивание работает на этом компьютере.

### Если YouTube не скачивается

YouTube иногда блокирует облачные серверы («подтвердите, что вы не бот»). Тогда:
- попробуйте позже или запустите сервер на своём компьютере (домашний интернет YouTube не блокирует);
- или добавьте на Render переменную `YTDLP_COOKIES` с cookies YouTube в формате Netscape
  (лучше от отдельного, не основного аккаунта).

TikTok, Instagram, VK и другие сайты обычно работают и так.

### Запасные способы

На странице «Видео» в блоке «Другие способы скачать» остались онлайн-сервисы (cobalt, SaveFrom и др.)
и готовая команда для `yt-dlp`. На Android есть приложение [Seal](https://github.com/JunkFood02/Seal).

Скачивайте только своё видео или то, что разрешено автором, — для личного просмотра.

## Телеканалы (футбол в прямом эфире)

В разделе «Футбол» есть плеер прямых трансляций. Встроены официальные бесплатные спортивные каналы
государственных телекомпаний (вещание с их собственных серверов):

| Канал | Страна | Примечание |
|---|---|---|
| Футбол | Таджикистан | государственный спортивный канал |
| QazSport | Казахстан | показывает только в Казахстане |
| Türkmenistan Sport | Туркменистан | вещает не круглосуточно |

Свой канал можно добавить кнопкой **«+ Канал»**: официальная ссылка трансляции `.m3u8` с сайта канала
или ссылка на YouTube-эфир / YouTube-канал. Если канал не открывается — он может сейчас не вещать,
работать только в своей стране или не разрешать показ на других сайтах; ссылку можно скопировать и открыть в VLC.

Пиратские трансляции платных каналов (как на сайтах вроде liveball) сюда специально не подключены.

## Запуск на компьютере

Сайт использует JavaScript-модули, поэтому его нужно открывать через локальный сервер, а не двойным кликом:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000
